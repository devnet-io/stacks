# Stacks RFC index

RFCs describe proposed or accepted changes. They are not statements of current runtime behavior.

| Status | Meaning |
| --- | --- |
| Draft | Under design; no implementation commitment. |
| Proposed | Ready for review. |
| Accepted | Direction approved but not necessarily implemented. |
| Implementing | Partial implementation exists; project status names the evidence. |
| Implemented | Current architecture and user documentation describe the behavior. |
| Superseded / Rejected | Preserved as rationale with its replacement or reason. |

Acceptance never means implementation or deployment.
